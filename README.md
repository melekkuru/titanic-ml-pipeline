# titanic-ml-pipeline

An end-to-end machine learning pipeline project built with Scikit-learn for Titanic survival prediction.

## Project Goals
- Practice feature engineering
- Learn preprocessing pipelines
- Handle missing values
- Apply encoding and scaling
- Train and evaluate classification models

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow
1. Data loading
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Preprocessing with Pipeline & ColumnTransformer
5. Train/test split
6. Model training
7. Cross-validation
8. Model evaluation

## Models
- Logistic Regression
- Random Forest (planned)

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- Classification Report
